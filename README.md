一句话结论
单点针（≤20 针）在 250k 下已饱和：开/关 ActKV 都是 100%，测不出差别。
多轮真实负载才拉开差距：同一个 232.8k 代码库 + 40 轮对话，开 ActKV 两次都是 24/24（100%），关掉两次都是 21/24（87.5%），失败题号与失败方式完全一致；且开 ActKV 时回答更短、单轮更快。
速度上两者 prefill 无差别（~7–9 分钟 / 450–575 tok/s）。
